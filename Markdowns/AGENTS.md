# AGENTS.md

## 0. 语言

中文。代码、文件名可英文。

## 1. 项目

NdFeB 系稀土永磁体的成分—性能预测与低成本配方筛选原型。输入成分，输出 Ms（emu/g）、Tc（K）、Hcj（kA/m）、原料成本（美元/kg，半定量）。

当前是中期 Demo，不是结题成果。性能均为预测值。

## 2. 优先级

1. 10/25 彩排、10/30 中期材料。
2. 数值合理、口径一致、可追溯。
3. 中期后：Hcj 数据治理 → 实验与成果线。

与优先级冲突的技术升级，先停下来说明取舍。

## 3. 红线

### 3.1 数据

- dataset/MP、NEMAD、shared 下的 raw/ 只读，不原地修改、覆盖、删除。
- 清洗、特征、模型、筛选结果写入对应 processed/。
- 删除、去重、标签冲突、域外判断都要留日志。
- 新增或重命名字段同步更新 data_dictionary.csv。
- 带 flagged_nonclosure 或 is_oxide 的样本不得当干净样本。
- Hcj 标签必须带测量温度与工艺；缺温度只进宽成分集，不进 2:14:1 室温集。
- 2:14:1 家族与宽成分数据分列统计，不得混报。

### 3.2 表述

- 不把预测写成实测，不把成本估算写成企业降本。
- 不引用未复核指标。
- 每个数字能定位到文件、页面或运行记录。
- 模型指标（R²、MAE 等）只存在 Demo 各任务的 output/meta.json 与 fold_metrics.csv，md 不复制。
- 数据事实可写进 md，但必须带核对日期与来源文件。

### 3.3 方法

- 允许 GNN 直接输出 Hcj（路线 B：多模态图模型，见 spec.md 5.5），前提四条同时满足：
  1. 图必须携带结构信息（按配方的晶体结构图），并显式拼接工艺/工况 token（制备路线、晶粒尺寸、晶界相与扩散、退火窗口、测量温度）；缺工艺字段的样本只进消融与对照，不进主结果。
  2. 与同切分的成分基线（XGBoost）对比；若无显著优于基线，结论写"无增益"，不硬上、不改口径美化。
  3. 切分按配方分组（GroupKFold on reduced formula），禁止随机划分。
  4. 结构覆盖率与工艺字段覆盖率写进 output/meta.json；缺失以掩码通道表示，不得均值填补后当真实输入。
- 不把推断的显微组织当实测输入；无坐标的表不得冒充结构图。
- 不做微磁学仿真与显微组织演化建模。
- 先保证成分基线可解释、可复现；GNN 不得替换现有 Demo 主结果，除非过硬门槛。

### 3.4 代码

- 不用旧 data/ 路径，统一 dataset/MP、NEMAD、shared 下的 raw 与 processed。
- 不写死本机绝对路径，外部目录可配置。
- 成分输入由 compose.py 统一生成化学式（待建）；建成后页面不得自行拼字符串。
- 临时脚本放 scripts/tmp/，完成后清理。
- 不自动 git commit 或 push。
- 大文件、模型权重、日志不入 git。
- 每个脚本前一句话注释说明作用。

## 4. 约定

- Python 3.9+。
- 依赖按需：pandas、NumPy、scikit-learn、XGBoost、pymatgen；路线 B 另需 torch（CPU 版）。
- 公共特征集中在 featlib.py。
- 标签统一 y_Ms、y_Tc、y_Hcj，保留上游字段。
- 单位：Ms emu/g，Tc K，Hcj kA/m；Hcj 建模用 log10(1+Hcj)，展示还原。
- 固定 random.seed、numpy.random.seed、torch.manual_seed。
